# Kancelaria Notarialna Piotr Suzanowicz — Siechnice

Projekt strony internetowej wykonany w **React + Vite + Tailwind CSS**, z zachowaniem pełnej struktury informacyjnej, sztywnych danych kancelarii, identyfikacji wizualnej opartej na oryginalnym znaku firmowym (`#0D254C` / `#7E97B8` / `#FFFFFF`) oraz wysokiego kontrastu (WCAG AAA) w menu nawigacji.

## Szybkie uruchomienie lokalne

```bash
npm install
npm run dev
```

## Wdrożenie na Vercel (przez GitHub)

1. Utwórz nowe repozytorium na GitHubie i wgraj do niego wszystkie pliki z tego archiwum.
2. Wejdź na [vercel.com](https://vercel.com), wybierz **Add New → Project** i zaimportuj repozytorium.
3. Vercel automatycznie wykryje **Vite** (`Build Command: npm run build`, `Output Directory: dist`). Kliknij **Deploy**.
4. Po kilkunastu sekundach otrzymasz gotowy link podglądowy (`*.vercel.app`), który możesz bezpośrednio przesłać notariuszowi.
